# Experiment 2 – Flutter Widgets and Layouts

## Aim

To build the To-Do application UI using common Flutter widgets and layout structures.

## Concepts demonstrated

- `Text`
- `Icon`
- `Container`
- `ElevatedButton`
- `Row`
- `Column`
- `Stack`
- Widget nesting
- `Scaffold`
- `AppBar`

## Project implementation

The Home screen uses `Column`, `Row`, `Container`, `Stack`, `Text`, `Icon`, `Checkbox`, and buttons to create the task interface. The Task Details screen also demonstrates a `Stack` with a positioned icon.

## Result

A basic To-Do List interface is designed using Flutter widgets and Row, Column, and Stack layouts.
