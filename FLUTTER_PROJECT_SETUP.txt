IMPORTANT:
This folder contains the complete application source for Experiments 2, 3 and 4.
The standard Flutter platform folders (android/, ios/, web/, etc.) are not included because
they are generated by Flutter and depend on the Flutter SDK installed on your computer.

If you open this folder in VS Code and want to run it:
1. Open Terminal in this folder.
2. Run: flutter create .
3. Run: flutter pub get
4. Run: flutter run

Do NOT delete the lib/ folder or pubspec.yaml before running flutter create .
